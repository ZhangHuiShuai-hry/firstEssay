# 限制与未完成项

1. **T03-0 PARTIAL**：已冻结版本/环境并实现节点组件计时，但未完整拆分 V0 的创建/翻译/native/读回/证书/列管理，不能精确量化每一来源的收益。
2. **性能公平性 PARTIAL**：75 臂全部真实运行，但名义 5 秒是软预算。B&P 结果与逐节点证书体积大，序列化/写盘不可忽略，最大总超预算约 3.95 秒。与 Compact 的严格相同总墙钟对照尚不成立；不可用其时间/Gap 排名宣称更优。应实现预算预留、checkpoint 和可中断外围后重跑。
3. **最终版本中等规模复跑 NOT RUN**：中等规模基于 source_snapshot；之后增加更严格 PP 数值检查、旧记录隔离及 V3 日志防覆盖，并全量复跑小规模。最终数值检查版本尚未重跑全 75 臂。
4. **T03-4 NOT IMPLEMENTED**：没有签发基于截断 PP bound 的新节点 UB。对应方向反转、遗漏凸性常数、缺块 bound 三个专项契约测试 NOT RUN。当前 native 最优 PP 的坏 bound 检查已单测，但这不替代截断契约。
5. **V2 仍有镜像成本**：native RMP 增量追加，PuLP 验证镜像仍重建。退化对偶导致树不同，single_line 的 V2 可处理更多节点；不能保证总时间降低。未声称 measured basis reuse ratio。
6. **V3 仅实现 compact_warm_start**：off 对应 V0–V2；restricted_ip 获取 NOT IMPLEMENTED。通过 witness 检查才设 LB，没有利用生成器见证；未把该 witness 的列注入根池，因此获取 LB 不自动加速 Phase I/UB。
7. 中等规模全部 time_limit，没有证明任何中等规模整数最优，也未独立枚举这些指数域；只能检查保存的 solver/树状态及 witness。小规模才有完整枚举与独立节点 LP/IP 重放。不能从小规模 PASS 推断大规模证书全部独立验证。
8. 每小规模版本只有单次完整运行，没有重复统计意义的加速结论；Compact 首解时间未解析，不能伪报零。中等规模只在 n20/30/40 的 5 seeds 汇总状态与耗时四分位数。
9. 原始数据保留约 2 GiB、上万文件。PP 加速使短预算内产生更多列与更大的逐轮 pool 快照，证书写盘会抵消收益。后续应使用不减少审计信息的内容寻址/追加式证据存储，再讨论上传及归档方式。没有删除失败记录以降低体积。
10. 浮点数值证明不是严格有理算术证明。所有异常 fail-closed，仍须依赖 CPLEX 最优/不可行状态的正确性；离线枚举认证作用域明确限于小规模。

当前建议：先解决时间预算与证书存储、完善细分剖析并重复较长预算的配对实验，然后评估定价策略。暂不开始 RL；尚无证据证明定价求解是唯一瓶颈，也没有足够稳定的严格公平性能基线。
