# 后续候选；尚未实现或运行，不作为结果

1. **轮内定价预算覆盖。** 若一条大线的定价占满全部剩余时间，其他线未被再次定价，应研究固定本轮对偶时给各线分配时间，至少尝试全部块，利用合法新列恢复整数方案。未完成全部精确定价仍不能启动一轮被标为精确的新CG或宣称LP最优；零价经济界也不等于已经实现一般非零对偶截断契约。先同输入比较后再改变默认调度。
2. **同质站点对称性。** 现有生成数据站点成本同质，空站位置可能增加原生搜索。可研究只在无原x分支固定的整线域内，对同质站点规范化空站位置。须证明压缩映射保留任务/模式、AND前缀、节拍、疲劳、H/R、回收和利润；异质站点不能套用。并给Compact加入同样有效的对称处理做加强对照，避免把一般建模收益全归因于CG。不改原始MILP源文件。
3. **固定总任务数、增加线数。** 两线80任务的PP每线40任务，本身已经较难。后续可预先冻结四线80任务（每线20）作线数因素实验，所有方法读取同一新输入，保留两线失败记录。它是另一物理实例，不能冒称同一模型输入上换了算法；跨线划分、必做任务位置和图边变化必须记录。
4. **最优利润与证明分开。** 如果分解UB更紧但LB低于Compact，只能报告界质量改善，不能说整数方案更好。如果两者利润相同但分解闭合，报告证明优势。只有留出规模重复结果稳定，且主要瓶颈确为定价选择，才讨论RL。
