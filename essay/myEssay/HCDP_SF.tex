\section{Reformulation and Empty Stations}
For each line $l$, let $\mathcal X_l$ be the finite binary set defined in the main manuscript. It contains selection, assignment, AND precedence, time, fatigue, recovery, and two-way configuration logic. It excludes global resource capacities.

Given a compact integer solution, extract every line's full assignment. Each extraction belongs to $\mathcal X_l$. Its profit includes exactly the original revenue and costs. Selecting one such plan per line preserves shared resource totals. Given an integer master solution, copy each selected plan to its line. Local constraints hold by membership. Shared constraints hold by the master rows. This proves both directions of integer equivalence.

Empty stations have no selected mode. The activation and deployment inequalities then force $u=h=r=0$. A nonempty station forces $u=1$. A human-involving mode forces $h=1$, and a robot-involving mode forces $r=1$. Conversely, a deployment value of one requires a corresponding mode. No unused deployment variable remains free. Entirely empty line plans are allowed only when required-task and recovery conditions permit them.

\section{LP Inclusion and Sparse Mixing}
Split each complete line plan into its station assignments. For each station pattern, sum the weights of all line plans containing it. Each station's weights sum to one. Expected task incidence, prefix incidence, recovery, resources, and profit remain identical. The induced station-column solution satisfies the complete station master. Expanding these station patterns into compact variables preserves all compact linear constraints. Hence
\begin{equation}
z^{\IP}=z_{\rm line}^{\IP}\leq z_{\rm line}^{\LP}
\leq z_{\rm station}^{\LP}\leq z_{\rm compact}^{\LP}.
\end{equation}
Equality between LP bounds is not assumed. Arbitrary restricted pools need not follow this ordering.

An extreme point of the line master has at most $|\mathcal L|+q$ positive columns, where $q\leq2$ is the additional rank of active resource rows. Each line needs at least one positive column. Thus at most $q$ lines mix multiple columns at such a point. An arbitrary convex combination of optima can mix more lines. Sparse mixing does not imply zero integer gap.

\section{Phase I and Dual Repair}
Phase I needs resource elastic variables only because every column already satisfies all local constraints. With one plan per line, convexity can be satisfied. Large enough elastic variables absorb resource violations. The restricted elastic master is therefore feasible.

If the complete line LP is feasible, use its weights and zero artificials in Phase I. Conversely, a zero-artificial optimum satisfies the real resource constraints. This equivalence concerns LP feasibility only.

For complete exact pricing, line $l$ has maximum reduced cost $\rho_l$. Raising its convexity dual by $\max(0,\rho_l)$ removes every complete-dual violation. Weak duality gives the repaired bound in the main text. The same proof applies to Phase I with zero real-column profit. A strictly negative complete Phase I repaired bound proves LP infeasibility.

A time-limited pricing incumbent is a lower bound on its maximization optimum. It does not certify absence of positive reduced cost. The framework attempts the remaining lines under the same duals and stops the CG loop if any maximum remains unproven. Earlier valid bounds and newly found legal columns remain available. An incomplete round is not labeled exact.

\section{Integer Resource Profiles}
A profile fixes exact human and robot counts $(a,b)$ on one line. Let $v_l(a,b)$ denote its best profit. Only $a\leq\min(k_l,h^{\max})$ and $b\leq\min(k_l,r^{\max})$ are needed for integer coordination. A globally feasible integer plan cannot exceed the entire shared capacity on one line. These limits do not restrict full-domain pricing.

The lower table uses feasible profits and $-\infty$ for profiles without a known witness. The upper table uses valid upper bounds, $+\infty$ for unknown bounds, and $-\infty$ only after reliable infeasibility proof. An upper-DP maximizing path can therefore require a new query rather than profile deletion.

Complete pricing provides the profile inequality
\begin{equation}
v_l(a,b)\leq\sigma_l+\max(0,\rho_l)+\pi_Ha+\pi_Rb.
\end{equation}
Economic initialization supplies another bound source. The stored UB takes the minimum of valid sources. Each profile query solves the original local MILP with exact resource-count equations. A valid native maximization Best Bound can tighten that profile UB before optimality is proved. This applies to the explicit profile domain. It does not establish a general contract for truncated nonzero-price CG rounds.

The lower DP selects a jointly feasible integer combination whenever it finds a path. The upper DP dominates every feasible original integer combination. Its bound can close below the complete line LP optimum. Consequently, integer closure through profiles does not imply LP convergence.

The archived positive-gap case has complete line-LP value 6.5 and integer optimum 2. Four profile queries close its integer gap. The LP-feasible/IP-infeasible case has line-LP value 4 and no integer plan. Nine queries prove its integer infeasibility. Both cases have archived CPLEX and CBC validation. Their different proof states explain the need for separate LP and integer labels.
